# MemoryCastle 🏰

File-based memory for AI agents, built on the method of loci: **the palace is the project's own topology**. Memories anchor to places (rooms with a `locus:`), occasions have fixed walks (routes with a mandatory completeness report), and an admission gate + consolidation patrol + decay path keep the whole thing trustworthy. Methodology first, SDK later.

**Why another memory system?** Most designs optimize *finding* memories (vector stores, rankers). The measured problems in real agent work are *trusting* them — what deserves storage, how raw notes become durable knowledge, how stale knowledge leaves — and *actually recalling* them at the right moment. MemoryCastle answers the first with a gatehouse and a patrol, and the second with space: you are standing in `src/payment/` → the payment room's memories load; the user says "release" → you walk the before-release route, every stop, and report 巡行 N/N. No infrastructure, reviewable in a diff.

## Layout

```
docs/architecture.md    the design: map, record format, gatehouse, patrol, walls, recall (§ numbers are the API)
templates/              keep / room / routes / chronicle scaffolds
skill/SKILL.md          session operating procedure (init / remember / recall / walk / consolidate)
scripts/castle-init.mjs zero-dependency scaffolder (Node)
plugins/memory-castle/  the same skill packaged as a Claude Code plugin (generated by scripts/build-plugin.mjs)
app/                    local companion app: Web UI + REST API + LLM adapters, Electron desktop build
.claude/castle/         this project's own memory — the self-hosted reference instance
```

## Install as a Claude Code plugin

```
/plugin marketplace add redseye/MemoryCastle
/plugin install memory-castle@memorycastle
```

Then in your project, run `/castle init` and follow the three manual steps it prints. Rooms are not invented up front — they are born when the consolidation patrol finds ≥3 chronicle entries sharing a place.

## Quickstart without the plugin

```
node scripts/castle-init.mjs <project-root> --name "My Project"
```

Fill the `{{...}}` placeholders in the generated `keep.md`, and add the one CLAUDE.md routing row the script prints.

Note: by design (architecture §2), generated castle instance files are written in Traditional Chinese — the palace is meant to be read by its human team; the spec, skill, and API docs are English.
